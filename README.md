# 🚀 DB Ninja - Shop Management System

A Full Stack Shop Management System built using **React, Node.js, Express.js, and MySQL**.

## 📌 Features

- 🔐 JWT Authentication
- 📊 Dashboard
- 📦 Product Management (CRUD)
- 📂 Category Management (CRUD)
- 👥 Customer Management
- 🛒 Order Management
- 💳 Payment Management
- 📈 Reports
- ⚙️ Settings Management
- 🛡️ Role Based Access Control (RBAC)

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- JWT Authentication

### Database
- MySQL

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Jeeva-523/DB-Ninja.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
